# Catalog Submission

## Required
- Public repository
- Passes `hermes plugins validate . --install-deps`
- One file PR to NousResearch/hermes-agent: `plugin-catalog/greenlight.yaml`
- Full 40-character commit SHA pinned
- Demo video showing the plugin working
- Form submission with both links
